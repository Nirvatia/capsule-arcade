# Дрейф — план работ

Дизайн: `DESIGN.md`. Прототип-референс: `prototypes/snake/drift-prototype.html`.

## Рабочее соглашение

- Логика (`sim/`, `pictures/`) — чистый TypeScript без DOM, покрыт тестами vitest.
- Вид (`view/`), звук (`audio/`) и UI (`ui/`) читают состояние, но не меняют правила.
- Все числа — в `config.ts`.
- Перед коммитом: `npm run check`, `npm test`, `npx eslint src/games/snake src/routes/games/snake`,
  Prettier на изменённых файлах.
- Визуальные изменения проверяются скриншотами в браузере (Playwright).

## Известные ограничения альфы

- Телефон в портретной ориентации: Полотно вписывается по ширине, клетка ~15 px — тесно.
- Морской конёк не вошёл: на сетке 24×14 не читался.
- Шрифт Raleway грузится с Google Fonts; без сети — системный шрифт.
