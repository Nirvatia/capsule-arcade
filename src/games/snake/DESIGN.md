# Дрейф — дизайн

Спокойная змейка без поражений. Игрок плавает светящейся змейкой в тёмной воде, собирает
искры и обводит по клеткам линии, из которых складывается рисунок морского существа.
Рисунок дорисовывается за несколько заходов, потом оживает и уходит в альбом.

Опора: прототип `prototypes/snake/drift-prototype.html` (концепт и петля понравились
владельцу; визуал, темп и «абстрактные узоры» — нет).

## Опорные решения владельца

| Тема            | Решение                                                                    |
| --------------- | -------------------------------------------------------------------------- |
| Платформа       | клавиатура в первую очередь, телефон тоже                                  |
| Место           | `src/games/snake/`, маршрут `/games/snake`, проверки проекта               |
| Длина           | сессия на ~10 минут залипания, но контента надолго                         |
| Картина         | линейный рисунок: каждый обведённый штрих — часть рисунка                  |
| Тема            | подводный мир, биолюминесценция                                            |
| Загадка         | силуэт угадывается к середине, имя открывается в конце                     |
| Готовые рисунки | альбом                                                                     |
| Темп            | обычный ход на поле, на линии змейка замедляется и прощает поздний поворот |
| Строгость       | обводить точно по клеткам                                                  |
| Зажигание       | штрих загорается сам, когда пройден целиком                                |
| Внешнее поле    | остаётся, но короткое — передышка                                          |
| Испытание       | нет: чистое залипание                                                      |
| Свет            | тёмная вода, мягкое свечение только у змейки и линий                       |
| Звук            | генеративный эмбиент, как в прототипе                                      |

## Петля

1. **Течение** (внешнее поле, 20–40 с). Свободный дрейф на 360°. Искры медленно плывут;
   рядом с головой они сами тянутся к ней. Пробел (тап) — «зов»: искры в большом радиусе
   подплывают. Когда собрано `SPARKS_NEED` искр, открывается портал; рядом с ним змейку
   мягко подтягивает. Вплыть в портал — нырнуть на Полотно.
2. **Полотно** (внутреннее поле, сетка). На сетке видна уже зажжённая часть рисунка и
   бледные штрихи текущего захода (3–5 штук). Змейка обводит штрих от любого из двух
   концов (концы отмечены звёздочками). Пройден целиком — загорается сам.
   Когда все штрихи захода горят, змейка выплывает обратно в Течение.
3. **Оживление.** После последнего захода сетка гаснет, ступенчатые линии плавно
   перетекают в гладкий рисунок, появляется имя («Кит»), рисунок покачивается.
   Он записывается в альбом, начинается следующий.

Один рисунок — 3–4 захода, около 4–6 минут. Десять минут — примерно два рисунка.
Когда все рисунки собраны, начинается новый «прилив»: те же рисунки в другой палитре
(альбом помнит оба).

## Управление

- Стрелки / WASD. На Полотне — повороты на 90°, на Течении — направление дрейфа (8 сторон).
- **Две стрелки сразу** (например → и ↓) на Полотне — змейка идёт лесенкой. Если впереди
  обводимый штрих, лесенка подстраивается под него.
- Пробел — зов искр (Течение). Esc / P — пауза. M — звук.
- Телефон: палец задаёт направление (вектор от точки касания). На Полотне диагональный
  сектор работает как две стрелки. Короткий тап — зов.

## Темп и прощение (жалоба «бот нажимает мгновенно»)

- Скорость на Полотне — `POND.CRUISE` клеток/с вдали от штрихов и `POND.TRACE`
  клеток/с рядом с необведённым штрихом. Переход плавный.
- Поворот можно нажать заранее (очередь из двух) или **с опозданием**: если голова ушла
  от центра клетки меньше чем на `POND.LATE_TURN` клетки, шаг перестраивается.
- Перед углом штриха за две клетки появляется метка поворота.
- Сбился со штриха — его прогресс обнуляется (строго), но штраф только в этом.

## Рисунки

- Сетка рисунка `24×14`. Штрих задаётся ломаной по вершинам-клеткам; между вершинами
  строится лесенка из соседних клеток, ближайшая к прямой. Одна вершина — «звезда»
  (глаз). Порядок штрихов — порядок обводки, заходы — числа штрихов по порядку. Парсер
  проверяет, что штрихи не выходят за сетку, не пересекают себя и друг друга.
- Диагонали рисуются лесенками; гладкий вид получается сглаживанием центров клеток
  (передискретизация + гауссово сглаживание, концы закреплены). Концы штрихов, которые
  касаются друг друга, соединяются — контур получается сплошным.
- Порядок штрихов выбран так, чтобы к середине угадывался силуэт.

Набор альфы: рыбка, медуза, морская звезда, кит, черепаха, осьминог, скат, краб.
Морской конёк на сетке 24×14 не читался (похож на птицу) — отложен.

## Визуал (вариант B «Возвращение цвета», в духе GRIS)

- Два мира. **Течение** — бледная акварельная вода: светлый градиент, свет сверху, мягкие
  лучи, дымка лаванды и серого, силуэты скал с аркой, водоросли, зерно бумаги. Каждый
  собранный рисунок возвращает в воду свой цвет — пятно акварели на своём месте.
  **Полотно** — лист тёплой бумаги: сетка едва видна точками, штрихи захода — карандашный
  пунктир со звёздочками тушью на концах, обведённое — тушь кистью, под ней расплывается
  цвет рисунка.
- Змейка живая: сужающееся тело, полупрозрачный плавник-лента с лучами в цвет рисунка,
  шлейф на хвосте, голова с миндалевидным глазом и усами. В воде она светлая, на бумаге
  становится тушевой — кистью. Контур строится по кускам пути: через край тело не
  растягивается; на углах сетки путь скруглён.
- Портал — энсо тушью; закрытый — карандашный круг. Искры — точки туши в мокром пятне цвета.
- Оживление: точки сетки гаснут, ступенчатые линии перетекают в гладкие, разливается цвет.
- Пост WebGL2: искажение у порталов и туннель между мирами; без bloom и тонмаппинга.
- Тяжёлая акварель рисуется заранее в отдельные холсты (вода, бумага, отгоревшая тушь,
  цвет готового рисунка); каждый кадр — только змейка, искры, свежие мазки, подсказки.
- Интерфейс: тушь на светлом, шрифт Cormorant Garamond.

## Звук

Пентатонический эмбиент: пэд в тональности рисунка, ноты за искры, мелодия при обводке
(каждая клетка — следующая нота гаммы), арпеджио за зажжённый штрих, аккорд за заход,
волна при оживлении. Громкость ниже, чем в прототипе.

## Сохранение

`localStorage` (`neo_arcade_snake_drift_v1`): номер рисунка, прилив, зажжённые штрихи,
собранные рисунки, выученные подсказки. Сохраняется после каждого штриха. Рекорд для
«Доски почёта» в меню зала — число собранных рисунков.
