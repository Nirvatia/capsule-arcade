# Каретка — геймдизайн

Учебная аркада про машину Тьюринга. Игрок — стажёр цеха «Бесконечная лента»: он пишет таблицы
команд для робота-каретки, а та честно (иногда слишком честно) исполняет их на ленте. Цель игры —
подготовить к тесту, где будет **одна задача на функцию** и **одна задача из задачника**, и
сделать это смешно.

Статус: черновик на утверждение (шаг 0 `ROADMAP.md`). Макет: `prototypes/turing/mockup`.

## 1. Обещание игроку

- Через 2–3 часа игры ты пишешь таблицу МТ для функции вида `f(x,y) = 3x, если x ≥ y, иначе 2y`
  и для задачи из задачника за время теста, на бумаге, без подсказок.
- Каждая ошибка видна глазами: каретка уезжает в пустоту, кружится в цикле, растерянно стоит
  без команды. Ошибка — это сценка, а не красная надпись.
- Таблица в игре выглядит **как на листке**: столбцы — состояния, строки — символы, в клетке
  `|Пq2`. Что набил в игре, то и пишешь на тесте.

## 2. Мир и персонажи

**Каретка** — робот, который и есть головка машины. Едет по рельсу над лентой, светит лучом в
текущую клетку, пишет пером, стирает ластиком, на груди табло с состоянием. Лицо — экран с
глазами; эмоции: спокойна, сосредоточена, рада, растеряна, кружится. Говорит коротко и сухо,
юмор — в буквальности: она делает ровно то, что написано.

**Заказчики** — у каждого цеха свой, с репликой на заказ, на успех и на каждую типовую ошибку:

| Цех                                   | Заказчик                                  | Шутка                                                         |
| ------------------------------------- | ----------------------------------------- | ------------------------------------------------------------- |
| 0. Обучение                           | Каретка сама                              | инструктаж «как не уехать в бесконечность»                    |
| 1. Палочки (унарные, зад. 5–7)        | Гусь Палочкин, счетовод                   | считает только палочками; лишняя палочка — «это уже налог»    |
| 2. Двоичный (зад. 1, 2, 8, 12а, 13а)  | Бабуля Бинарова                           | вяжет носки из нулей и единиц, путает «перенос» с «переездом» |
| 3. Троичный (зад. 3, 4, 9, 13б)       | Профессор Тройкин                         | «в наше время цифр было три, и всем хватало»                  |
| 4. Десятичный (зад. 10, 11, 12б, 13в) | Мэр Десятичный                            | всё хочет «как у людей», в столбик                            |
| Ф. Отдел функций                      | Инспектор Эф (папка с моноклем и печатью) | приносит функции на бланках «в трёх экземплярах»              |
| Экзамен                               | Сова-экзаменатор                          | молчит. Смотрит. Ставит печать                                |

Примеры реплик (банк растёт в шаге 7):

- Цикл: «Я проехала 10 000 клеток. Это не баг, это кардио.»
- Нет команды: «q3 видит `*`. Инструкции нет. У меня экзистенциальный кризис.»
- Уехала в пустоту: «Тут только λ. Красиво, но ответа нет.»
- Лишний мусор: Гусь — «Га? Я просил три палочки, а тут ещё звёздочка. Звёздочку оставьте себе.»
- Успех, Инспектор Эф: «Принято. Оформлено. Заверено. Можете идти… то есть ехать.»

## 3. Основной цикл

1. **Заказ.** Карточка: заказчик, условие (дословно из задачника или бланк функции), примеры,
   алфавит, подсказка-приём (скрыта).
2. **Таблица.** Игрок заполняет матрицу «символ × состояние». Клетка: что записать, куда ехать
   (Л / Н / П), в какое состояние. Можно добавлять состояния и вспомогательные символы-метки.
3. **Прогон.** Шаг, шаг назад, пуск, скорость, точка останова на состоянии. Каретка едет,
   активная клетка таблицы подсвечена, строка конфигурации пишется как в тетради
   (`|||q3*||` ⊢ …).
4. **Сдача.** Машина прогоняется на всех тестах заказа (примеры + скрытые). Каждый тест —
   отдельная карточка с итогом и сценкой при провале.
5. **Награда.** Печать «ВЫПОЛНЕНО», конфетти, XP, звёзды, реплика заказчика.

Звёзды за заказ: ★ решено · ★ без подсказок · ★ состояний не больше эталона. Шаги — для
таблицы рекордов, не для звёзд (на тесте важна верность, а не скорость).

## 4. Правила машины (соглашения владельца, 2026-11-24)

- Лента бесконечна в обе стороны, пустой символ — `λ`.
- Начальное состояние `q1`, остановка — переход в `q0`. Сдвиги: `L`, `R`, `S`.
- Команды пишутся списком, по одной в строке: `q1 | → q2 λ L` (как в `Turing.html` владельца);
  при многих командах — постраничный список, не бесконечная прокрутка.
- Число `n` записывается `n + 1` палочками (ноль — одна палочка), аргументы разделены `*`.
- В начале головка над самым левым символом входа; где она после остановки — неважно.
- В конце на ленте ровно ответ: без дыр, меток и разделителей.
- **Частичные функции**: на входах вне области определения машина обязана работать вечно
  (вечный цикл в одной из веток), а не останавливаться. Пример: `x − y + z` при `x + z < y`.
  У `|x − 4| / 2` на занятиях брали `x ≥ 4` и чётный.
- Нет команды для пары (состояние, символ) — аварийная остановка, тест провален.
- Проверка «вечного цикла» в игре — по лимиту шагов или повтору конфигурации.
- Вспомогательные символы-метки разрешены, в ответе их быть не должно.

## 5. Типы задач

### 5.1 Задачник — 28 заказов

перенос через все разряды, равные числа, ноль в ответе). У каждой — проверенное эталонное
решение (прогоняется в `npm test`).

| --- | -------------------------------------------------------------------------- | --------- |

### 5.2 Функции — новый тип

Заказ — формула. Числа — натуральные с нулём, **в унарной записи**: `x` — это `x` палочек,
аргументы разделены `*`, ответ — `f` палочек, ноль — пустая лента. Пример:
`f(x,y) = 3x, если x ≥ y, иначе 2y`, вход `|||*||` (x = 3, y = 2) → `|||||||||`.

Для частичных функций на бланке пишется область определения, тесты берутся только из неё:
`f(x,y,z) = x − y + z` при `x + z ≥ y`; `f(x) = |x − 4| / 2` при чётном `x`.

**Каталог** (с эталонными решениями и разбором): три примера владельца и ещё ~20 по семействам.
**Генератор** (бесконечная практика): шаблоны с параметрами, проверка — прогоном на случайных
входах из области определения. У сгенерированных нет готового решения, только разбор на приёмы.

| Семейство            | Примеры                                                                      |
| -------------------- | ---------------------------------------------------------------------------- |
| Линейные             | `x + y`, `2x`, `x − y + z`, `2x + y`, `x ∸ 3`                                |
| Сравнения и ветки    | `3x, если x ≥ y, иначе 2y`; `max(x,y)`; `min(x,y)`; `x, если x = y, иначе 0` |
| Модуль и деление     | `\|x − 4\| / 2`, `⌊x/2⌋`, `x mod 2`, `\|x − y\|`                             |
| Комбинации (сложные) | `2·max(x,y) − min(x,y)`, `\|x − 2y\| + 1`                                    |

**Разбор на приёмы.** Каждая функция раскладывается на шаги-приёмы; разбор — чек-лист на
карточке («1. сравнить зачёркиванием 2. ветка: утроить x / удвоить y 3. убрать мусор»), игрок
отмечает этапы, подсказка открывает их по одному.

### 5.3 Приёмы (обучение)

Цех 0 и первые заказы каждого цеха учат по одному приёму. Освоенный приём — «чип» в коллекции
с мини-шаблоном таблицы; на тесте их нет, поэтому шаблоны открываются только в обучении.

Пробег до края · стирание · склейка (убрать разделитель) · челнок (пометил — отвёз — вернулся) ·
сравнение зачёркиванием · копирование · деление пополам · перенос разряда · сдвиг блока.

### 5.4 Разминки (по 1–2 минуты, между заказами)

- **Предскажи ленту**: дана таблица и вход — что будет на ленте.
- **Трассировка**: записать 3–5 конфигураций, как в тетради.
- **Найди баг**: таблица с одной ошибкой, каретка показывает сценку — исправь клетку.

## 6. Прогрессия

Карта — цепочка цехов на конвейере. Цех 0 → Цех 1 → дальше ветвится: цеха 2–4 и Отдел функций
открываются после цеха 1, экзамен — после первого заказа в Отделе функций и пяти из задачника.
Ранги по XP: Стажёр → Наладчик → Оператор ленты → Мастер цеха → Главный инженер →
**Тьюринг-полный**. Серия — дни подряд хотя бы с одним заказом. Награды — значки за сценки
(«Первая бесконечность», «Уехала за горизонт», «Ни одного лишнего состояния»).

## 7. Пробный экзамен

Как на настоящем тесте: **одна функция + одна задача из задачника**, случайные. Таймер
20 / 40 / 60 мин. Подсказок, разборов и шаблонов нет. Запуск — только на примере из условия
(как трассировка на листке). Полная проверка — после «Сдать». Итог: печать Совы, разбор по
каждому тесту, реплики каретки по ошибкам, ссылка «потренировать этот приём».

## 8. Редактор таблицы

- Матрица: столбцы `q1…qn`, строки — символы алфавита задачи + `λ` + метки. Клетка — `|Пq2`,
  пустая клетка — «—» (нет команды).
- Ввод мышью (поповер: символ / сдвиг / состояние) и клавиатурой: набрал `|пq2`, Enter,
  стрелки — к соседней клетке. Русские и латинские `Л/L`, `П/R`, `Н/S`.
- Активная при прогоне клетка подсвечивается, использованные — отмечаются, неиспользованные
  в конце можно показать (лишние состояния).
- Комментарий к состоянию («q2: везу палочку направо») — так учат писать на тесте.

## 9. Визуальный стиль и правила экрана

Это игра, а не страница. Главное правило: **понятно без чтения**.

- **Один холст.** Весь экран рисуется на canvas в логических 1600×900 и масштабируется целиком;
  никаких HTML-карточек, списков и абзацев.
- **Мир сверху, пульт снизу.** Сверху цех: лента и каретка, крупно. Снизу — таблица команд как
  пульт машины. Справа на пульте только кнопки: назад, большой «пуск», шаг, сначала.
- **Задание — картинкой.** Карточка «было → надо»: две мини-ленты со стрелкой. Рядом лампочки
  тестов: серые, жёлтая — идёт прогон, зелёные/красные — итог. Заказчик говорит одну короткую
  фразу в пузыре, и то не всегда.
- **Таблица из тех же плиток.** Строки — плитки ленты (`|`, `∗`, `λ`), столбцы — чипы `q1…qn`.
  В клетке три значка: плитка «что пишу», стрелка «куда еду» (← · →), чип «куда дальше».
  `q0` с флажком — стоп. Пустая клетка — пунктирное гнездо. Выбор клетки открывает поповер из
  трёх рядов: «пиши / едь / потом».
- **Жёлтый — это «сейчас».** Луч каретки, клетка ленты под ней, символ строки, чип состояния и
  выполняемая клетка таблицы светятся одним жёлтым — видно, какое правило сработало.
- **Цветов мало.** Нейтральный тёмно-синий цех и панели, кремовая лента, коралловая каретка
  (единственный акцент; ей же окрашена кнопка «пуск»). Зелёный и красный — только результаты.
- **Текст** — только название уровня, три слова в поповере и реплики. Шрифты: Unbounded
  (название, «ГОТОВО»), Tektur (подписи), JetBrains Mono (`q`-чипы).

## 10. Звук

Синтезируется (WebAudio): тик шага, перо, ластик, сдвиг рельса, печать, конфетти. Каретка
«говорит» короткими писками в ритм реплики. Отключается кнопкой в HUD.

## 11. Экраны

1. **Игровой экран** (макет `prototypes/turing/mockup`, кадры: прогон, редактирование клетки,
   «ГОТОВО»). Один и тот же для задачника и функций; у функции на карточке задания — пример
   `x, y → f`, формула показывается в названии уровня.
2. **Карта цехов** — следующий макет, после одобрения игрового экрана.
3. **Экзамен** — тот же игровой экран с таймером в HUD и двумя вкладками-задачами, без подсказок.
